# Student Accommodation Management Platform

A web-based platform that digitizes the student accommodation lifecycle — discover → apply → review → allocate → onboard → manage — for accommodation providers serving NWU and VUT students.

## Status
🚧 In early development — repository scaffolding and Supabase setup in progress.

## Stack
- **Frontend:** React + TypeScript, TanStack Query, React Router
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL via Supabase
- **Auth:** Supabase Auth
- **Storage:** Supabase Storage
- **Security:** PostgreSQL Row Level Security (RLS)
